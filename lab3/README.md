# Лабораторна робота 3

Створення адаптивного модального вікна з використанням слотів,
ref, Teleport і Transition.

## Можливості

- Фільтрація матеріалів за назвою та темою.
- Підрахунок кількості матеріалів і загальної тривалості.
- Редагування назви та тривалості через модальне вікно.
- Перевірка непорожньої назви та додатної цілої тривалості.
- Видалення матеріалу після підтвердження.
- Скасування кнопкою, хрестиком, Escape або натисканням на підкладку.
- Утримання фокуса всередині вікна та повернення після закриття.
- Блокування взаємодії з фоном і його прокручування.
- Адаптивне розташування кнопок і прокручування довгого вмісту.

Дані зберігаються в пам’яті. Оновлення сторінки відновлює
початкові матеріали. HTTP-запити, маршрутизація та localStorage
не використовуються.

## Середовище та залежності

- Node.js 24.13.0
- Vue 3
- Vite 8.3.5
- Tailwind CSS 3.4.17
- PostCSS 8.5.6
- Autoprefixer 10.4.21

Точні версії залежностей зафіксовано в package-lock.json.
Preflight у Tailwind вимкнено для збереження оформлення каталогу.

## Запуск

Команди виконуються з каталогу lab3.

```cmd
npm ci
npm run dev -- --port 5173 --strictPort
```

Адреса: http://localhost:5173/

## Збірка та перевірка

Спочатку зупинити dev-сервер через Ctrl+C.

```cmd
npm run build
npm run preview -- --port 4173 --strictPort
```

Адреса перевірки збірки: http://localhost:4173/
Зупинка preview: Ctrl+C.

## Структура

- src/App.vue — шапка, дані студента та композиція сторінки.
- src/components/MaterialCatalog.vue — робочий список, фільтри,
  вибір за id, чернетка редагування та підтвердження видалення.
- src/components/MaterialFilterForm.vue — поля фільтрів,
  події apply і clear.
- src/components/MaterialCard.vue — картка матеріалу,
  події select, edit і delete.
- src/components/ModalDialog.vue — універсальна оболонка діалогу.
- src/data/materials.js — початковий масив матеріалів.
- src/style.css — стилі каталогу та директиви Tailwind.
- tailwind.config.js — налаштування Tailwind.
- postcss.config.js — підключення Tailwind і Autoprefixer.

## Контракт ModalDialog

Пропси:

- modelValue: Boolean, початково false — стан відкриття.
- title: String, обов’язковий — заголовок.
- initialFocus: DOM-елемент або null — початковий фокус.
- fallbackFocus: DOM-елемент або null — ціль повернення фокуса,
  якщо кнопка виклику більше недоступна.

Подія:

- update:modelValue — передає false при запиті закриття.
  Використовується через v-model.

Слоти:

- default — форма редагування або текст підтвердження.
- footer — кнопки поточного сценарію.
  Без переданого вмісту показується кнопка «Закрити».

У каталозі використано один постійний екземпляр ModalDialog.
Компонент не змінює пропси безпосередньо.

## Teleport і Transition

Teleport переносить підкладку в body поза контейнером #app,
зберігаючи логічний зв’язок із каталогом.

Transition керує появою та зникненням підкладки.
Фон відновлюється після after-leave або під час демонтажу.
Для prefers-reduced-motion перехід вимикається.

## Реактивний ref і шаблонний ref

Реактивний ref зберігає стан, наприклад isOpen або selectedId.
У JavaScript його значення доступне через .value.

Шаблонний ref надає посилання на DOM-елемент для керування
фокусом. До монтування та після демонтажу він може бути null.

Слоти передають розмітку з каталогу до оболонки діалогу.
Переданий вміст має доступ до стану батьківського компонента.

## Перевірки

Перевірено редагування, збереження, скасування, валідацію,
підтвердження видалення, Escape, Tab і Shift+Tab,
повернення фокуса та блокування фону.

Перевірено розміри:
360×800, 768×1024, 1440×900, 844×390.

На ширині 639 px кнопки розташовані вертикально,
на 640 px — горизонтально.

Перевірено довгий вміст і масштаб 200%.
Тимчасові тестові абзаци після перевірки видалено.

Виробничу збірку перевірено через npm run preview.
