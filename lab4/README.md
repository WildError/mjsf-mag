## Структура проєкту

- `src/App.vue` — три незалежні набори вкладок.
- `src/components/tabs/Tabs.vue` — навігація, реєстрація вкладок і спільний контекст.
- `src/components/tabs/Tab.vue` — панель вкладки та кешування її компонента.
- `src/components/tabs/tabsKey.js` — Symbol-ключ для provide/inject.
- `src/components/demo-panels/OverviewPanel.vue` — текстова нотатка.
- `src/components/demo-panels/RequirementsPanel.vue` — прапорці та лічильник перевірок.
- `src/components/demo-panels/EnvironmentPanel.vue` — інформація про середовище, модальне вікно та лічильник відкриттів.
- `src/components/ModalDialog.vue` — модальне вікно.
- `src/style.css` — підключення Tailwind і загальні стилі.
- `tailwind.config.js` — налаштування кольорів, шрифтів та пошуку класів.

## Контракт Tabs

Властивості:

- `modelValue` — обов’язковий рядок, slug активної вкладки.
- `variant` — оформлення: `underline`, `pills` або `boxed`; типово `underline`.
- `title` — заголовок набору вкладок.

Подія:

- `update:modelValue` — передає slug вибраної вкладки та забезпечує роботу v-model.

Default slot містить компоненти Tab.

## Контракт Tab

Властивості:

- `slug` — обов’язковий унікальний ідентифікатор вкладки в межах одного Tabs.
- `title` — обов’язкова назва вкладки.
- `disabled` — робить вкладку недоступною; типово false.
- `panel` — компонент для динамічного відображення.
- `panelProps` — об’єкт властивостей динамічного компонента.

Default slot має пріоритет над властивістю panel і надає значення isActive.
У слоті потрібно розміщувати один компонент панелі.

Slug має залишатися незмінним протягом існування Tab.

## Provide/Inject

Кожен Tabs створює власний контекст:

- `activeSlug` — поточна вкладка, доступна лише для читання.
- `idPrefix` — унікальний префікс ідентифікаторів.
- `setActiveTab(slug)` — перемикання вкладки.
- `registerTab(...)` — реєстрація вкладки.
- `unregisterTab(slug)` — видалення вкладки з реєстру.

Tab отримує контекст найближчого Tabs через inject.
Використання Tab поза Tabs і повторення slug спричиняють помилку.
Якщо активну вкладку видалено або вимкнено, вибирається перша доступна.

## Слоти та динамічні компоненти

Перший набір передає панелі через слоти.

Другий набір створює вкладки через v-for із масиву конфігурації.
Панелі відображаються через component :is, а їхні властивості передаються через v-bind.

Третій набір містить недоступну вкладку та окремі екземпляри панелей.

Кожен набір має власний v-model. Перемикання одного набору не змінює інші.

## Збереження стану

KeepAlive кешує компонент кожної панелі.

Оболонка панелі приховується через v-show, а її компонент активується та деактивується через v-if усередині KeepAlive.

Після повернення на вкладку зберігаються:

- введена нотатка;
- вибрані прапорці;
- кількість перевірок;
- кількість відкриттів модального вікна.

Окремі екземпляри EnvironmentPanel мають незалежні лічильники.

## Доступність

- Використані ролі tablist, tab і tabpanel.
- Кнопки та панелі пов’язані через aria-controls і aria-labelledby.
- aria-selected позначає активну вкладку.
- Активна кнопка має tabindex="0", решта — tabindex="-1".
- Стрілки ліворуч і праворуч циклічно перемикають вкладки.
- Home відкриває першу доступну вкладку, End — останню.
- Недоступні вкладки пропускаються.
- Під час перемикання клавіатурою фокус переходить на відповідну кнопку.
- Модальне вікно закривається через Escape і повертає фокус на кнопку відкриття.

## Перевірка

Вручну перевірено:

- незалежність трьох наборів вкладок;
- перемикання мишею та клавіатурою;
- пропуск недоступної вкладки;
- збереження нотатки, прапорців і лічильників;
- відкриття та закриття модального вікна;
- розблокування сторінки після закриття вікна;
- адаптивність на розмірах 360×800, 768×1024, 1440×900 та 844×390;
- відсутність горизонтального прокручування сторінки.
